SHAPE KEY
  hdr     DMA tag 0x2000000N + VIF FLUSHE + DIRECT N (OT packet header)
  E4      REGLIST regs 0x42142142142160 (PRIM, TEX0, 4 x RGBAQ/ST/XYZ2): quad as strip, colour per corner
  C4      REGLIST regs 0xF42424242160 (one RGBAQ + 4 x ST/XYZ2) or 0xF42142142160 (tri, 3 x RGBAQ/ST/XYZ2)
  U3      REGLIST regs 0xF4141410: untextured Gouraud triangle (prim 0xB)
  L2      REGLIST regs 0x4410: line, flat colour
  AD1     A+D packet 0x1000000000008002, regs 0xE (one register, two loops: TEX0 / CLAMP / TEST between draws)
  PRIM    0x1C strip Gouraud tex; 0x5C same +ABE; 0x14 / 0x54 strip flat tex (+ABE); 0x1B / 0x5B tri Gouraud
          tex (+ABE); 0x0B tri untextured; 0x46 sprite untextured +ABE; 0x41 line +ABE; +0x200 = context 2.

State that later draws depend on (must be carried by any record conversion):
  - Ot_AddRestoreEnv (gfx_ot.c:248) leaves ALPHA 0x44, ZBUF write-masked, TEST 0x70000, TEX1 0, CLAMP 5.
  - Ot_NewHead/Ot_BuildHeads set ALPHA_1/2 per layer (layer0 0x44/0x42, layer1 0x48/0x49); every OT draw of
    that layer inherits it; prims choose context 1/2 by bit 0x200.
  - AD1 packets inside OT chains (TEX0 eft_ad_b/eft_ae, CLAMP eft_b geyser, TEST eft_e water) set state for the
    draws queued after them in the same slot.
  - EftStageScroll_Draw (eft_b.c:1306) leaves ALPHA 0x44, TEST 0x50000, CLAMP 0 for the stage draws after it.
  - Gfx_PutDefaultEnv (gfx.c:262) is the base ctx1 state of every 2D packet (TEXA, XYOFFSET, SCISSOR, FRAME, TEST,
    FBA, ZBUF, ALPHA, CLAMP, PRMODECONT, COLCLAMP, TEX1).
  - HUD mask / add packets (hud_a_b, hud_a_d, hud_d_b) set FRAME masks, FBA and destination-alpha tests that the
    next HUD sprites read; mirrored in gRndCtx by Rnd_Set*; the alpha plane they write is read by
    TEST_2 0x3C000 draws (and by the PVR, which drops mark-test 2D draws).
  - ObjGs_* (gfxm_e.c) and BtlObjDraw_SetEnv / ObjGs_AddFadeEnv (gfxm_d_c.c) set the env the VU1 model programs
    draw with (their GIF tags carry only PRIM / vertices).
  - Shadow pass renders to page 0x150, read back as a texture by ObjShadow_Draw (prog 6).
  - GfxPost / StgBlur / StgFog / ScrWarp use work pages 0x150/0x16C/0x170/0x1F6/0x1F8 (texture 0x2A00/0x2D80)
    as render targets then textures; Gfx_ClearScreen alpha clears (gfxm_d_b.c:101/143) prepare the alpha plane
    that ObjOutline / ObjGlow / GfxAlphaKey read.
